# Alpha Client

A free launcher for Minecraft: Java Edition on Windows. It sets up Fabric instances, finds mods, resource packs and shaders on Modrinth, and launches the official game.

It's not a cheat client: Alpha is a launcher and mod manager, and it doesn't add anything that gives an unfair advantage.

## Install

1. Install Python 3.9 or newer from [python.org](https://www.python.org/downloads/) and tick **"Add python.exe to PATH"** during setup.
2. Download **Alpha Client.pyw** from this repo.
3. Double-click it. The first launch installs what Alpha needs and adds a desktop shortcut.

## Updates

Alpha checks this repo for new versions. When one is out, Alpha shows **"New update ready to download"**. Click **Download update** and Alpha restarts on the new version, keeping your instances, settings and account.

## Privacy

Alpha has no server, analytics or tracking. Sign-in tokens stay on your computer, in the `.alpha` folder in your user folder.
